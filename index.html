Running a pair

Android desk

Starts the relay, then the Android half. Keep the tunnel URL — it changes on every restart.

MEDTALK_RELAY_TOKEN=<secret> \
  python3 scripts/medtalk-relay-server.py

cloudflared tunnel --url http://localhost:8787

RUN_ID=run1 RELAY_URL=<url> \
MEDTALK_RELAY_TOKEN=<secret> \
  scripts/medtalk-remote-android.sh

iPhone desk

Same RUN_ID and RELAY_URL, exactly. Find the udid with xcrun xctrace list devices.

RUN_ID=run1 RELAY_URL=<url> \
MEDTALK_RELAY_TOKEN=<secret> \
DEVICE_ID=<iphone-udid> \
  scripts/medtalk-remote-ios.sh

Reading a red run

A rendezvous timeout names the healthy device — the side that timed out was working. Read the other column first.

Exit 2 is infrastructure (device or relay gone), never a product defect.

Direction is not a free choice. Solo is patient-dials-only, so whoever dials is the patient — a2i has Android as patient, i2a swaps both roles. These are real, billed calls.
